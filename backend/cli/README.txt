================================================================================
                               命令参数
================================================================================

故障描述（位置参数）
    故障的自然语言描述

    示例: python -m cli.main "车辆无法上电"

-i, --interactive
    启动交互式诊断模式，可以连续多次诊断

    示例: python -m cli.main -i

--role <角色>
    指定用户角色，不同角色输出详细程度不同

    可选值:
        owner           - 车主 (通俗易懂的语言)
        tech            - 技师 (专业术语，详细诊断)
        technician      - 技师 (同 tech)
        service         - 客服 (友好专业)
        customer_service - 客服 (同 service)

    示例: python -m cli.main "车辆无法上电" --role tech

--model <模型>
    指定使用的LLM模型

    可选值:
        GLM-5-FP8       - GLM-5 FP8 模型 (默认)
        MiniMax         - MiniMax 模型
        MiniMax-M2.5    - MiniMax M2.5 增强版
        MiniMax-M2.1    - MiniMax M2.1 稳定版

    示例: python -m cli.main "车辆无法上电" --model MiniMax

--ontology <路径>
    指定本体文件路径（默认自动检测）

    示例: python -m cli.main "故障描述" --ontology C:\path\to\ontology.ttl

-v, --verbose
    启用详细输出（显示调试信息）

    示例: python -m cli.main "故障描述" -v

--version
    显示版本信息

--help
    显示帮助信息


================================================================================
                               使用示例
================================================================================

# 示例1: 基本诊断（车主角色）
python -m cli.main "踩刹车按启动按钮，车辆无法上电"

# 示例2: 技师角色诊断
python -m cli.main "停放超过1小时后车辆无响应" --role tech

# 示例3: 指定LLM模型
python -m cli.main "车辆无法上电" --model MiniMax

# 示例4: 技师 + 指定模型
python -m cli.main "车门打开后车辆没有自动上电" --role technician --model MiniMax-M2.5

# 示例5: 交互式模式
python -m cli.main -i

# 示例6: 详细输出模式
python -m cli.main "故障描述" -v


================================================================================

================================================================================
                               诊断输出说明
================================================================================

诊断结果包含:

【故障摘要】
    一句话概括故障情况

【故障分析】
    逐步分析推理过程

【可能原因】
    列出可能的原因及置信度

【排查步骤】
    具体的检查步骤，按优先级排序

【诊断置信度】
    整体诊断的置信度百分比

【建议】
    根据角色给出不同的建议

================================================================================
                               故障排除
================================================================================

1. 无法加载本体文件
   - 检查 ontology 文件路径是否正确
   - 使用 --ontology 参数指定正确路径

2. LLM连接失败
   - 检查网络连接
   - 确认 API Key 正确
   - 检查 LLM 端点是否可访问

3. 诊断结果不准确
   - 尝试使用不同的模型 (--model)
   - 使用技师角色获取更详细的分析
   - 更详细地描述故障症状
